Urban development and rising vehicular traffic patterns create major issues with congestion together with environmental problems. To address this issue, this project presents an AI-driven Traffic Monitoring System that dynamically suggests the least congested routes using real-time data analysis and 6G technology for ultra-low latency processing. Activity Management via Deep Learning uses computer vision reinforcement alongside deep learning to study current traffic videos and identify trafficblockages while offering best route alternatives. The system achieves fast and low latency traffic analysis through YOLOv8 based vehicle detection and graph-based pathfinding algorithms while taking advantage of 6G network capabilities to perform dynamic rerouting. The system uses MongoDB to store data together with Twilio API notifications . Urban mobility reaches enhancement through autonomous traffic management thanks to this solution which outperforms static sensor-based traffic systems and manual control features. This system benefits smart cities by selecting intelligent routes and analyzing future traffic flow data which leads to shorter journeys and reduced carbon emissions and lower fuel costs thereby optimizing transportation networks
